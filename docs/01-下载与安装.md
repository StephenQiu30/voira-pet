# 下载与安装

## 需求与验收

FR-PET-001：用户可通过GitHub Release下载DeepSeek独立宠物包，或从npm registry使用npx voira-pet将同一份已校验素材安装到桌面客户端的本地宠物目录。

- AC-PET-001：ZIP解压后包含voira-deepseek/pet.json和spritesheet.webp，manifest声明spriteVersionNumber为2，图片哈希与正式素材一致。
- AC-PET-002：npx voira-pet入口无运行时依赖，无子命令时默认安装DeepSeek，默认使用CODEX_HOME/pets或~/.codex/pets，支持通过--dir指定父目录；安装后得到同一份manifest和图片。
- AC-PET-003：重复安装相同素材不修改已有文件；不同素材、残缺包及目标符号链接均停止覆盖，保留用户内容。未知角色在创建目录前失败。
- AC-PET-004：安装器不改变当前活动宠物、不读取账号凭据、不调用收费服务。本地安装不等于网页端云收藏同步。

## 设计

DES-PET-001：使用Node.js 20以上的原生模块。bin/voira-pet.mjs是用户命令入口，src/installer.mjs维护固定角色清单、SHA-256校验、默认目录和安装。素材随npm包携带，安装器不另行下载或执行第三方代码；发布的tgz可直接通过npx的HTTPS包地址运行。

安装前先校验正式manifest和图片。目标目录使用独占创建，图片先写、manifest最后写；创建失败时只清理本次创建的文件及空目录。已有相同包返回已安装，任何不匹配均不覆盖，不提供强制替换或删除命令。

原始设定图、生成中间图、上传会话和个人云宠物ID不进入npm包。源码仓库保留完整展示资源；npm files白名单只保留CLI，以及DeepSeek与ChatGPT安装必需的manifest和精灵图。

本地格式依据本机ChatGPT内置hatch-pet的codex-pet-contract：id、displayName、description、spriteVersionNumber和spritesheetPath为manifest字段，v2精灵图为1536×2288。使用方式另参见[官方Pets说明](https://learn.chatgpt.com/docs/pets)。

npm registry为简写安装的正式入口，发布时使用public访问级别及latest标签，用户安装无需登录npm。GitHub HTTPS tgz保留为固定版本备用入口；仅该备用入口在npm 12须传入--allow-remote=root，对本次根安装包显式授权，不改全局配置。规则来源为[npm安装来源配置](https://docs.npmjs.com/cli/v12/commands/npm-install/#allow-remote)，入口示例统一见项目README。

当前源码0.2.0默认安装DeepSeek，并支持`install chatgpt`；公开npm仍为0.1.0，仅含DeepSeek。源码中ChatGPT独立安装到voira-chatgpt，不改变默认角色与既有内容。GitHub Release v0.1.0仍只有DeepSeek包。角色特有规则见[ChatGPT宠物](02-ChatGPT宠物.md)，正式分发状态只按实际发布结果维护。

## 验证与交付

T-PET-001／TC-PET-001：原生Node测试覆盖安装、路径、重复安装、内容冲突、符号链接及非法参数，对应AC-PET-002—004。

T-PET-002／TC-PET-002：从npm pack生成的tgz经npx实际安装到临时目录；检查manifest和素材哈希，对应AC-PET-001—003。发布后再验证GitHub HTTPS包安装及下载资产。

T-PET-003／TC-PET-003：GitHub Release附带独立宠物ZIP、npx用tgz及SHA256SUMS，对应AC-PET-001／002。下载和打包通过不代替逐平台真实客户端验收。

T-PET-004／TC-PET-004：发布后从官方registry回读version、latest与tarball integrity；使用空缓存及空用户配置，在仓库外以npx --yes voira-pet和临时CODEX_HOME完成默认安装，核对manifest、WebP哈希及重复安装不修改文件，对应AC-PET-002—004。
